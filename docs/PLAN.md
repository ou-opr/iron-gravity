# 「铁引力 · IRON GRAVITY」健身网站 — 调研、方案与自我审核

> 由 Hermes 于 2026-10-15 自主完成。记录：①网上调研结论 ②网站方案 ③方案自审与修订 ④构建与验证记录。

## 一、调研结论

### 1.1 现有产品扫描（我们缺什么）
- **MuscleWiki**（musclewiki.com）：2000+ 动作 + 交互肌肉图 + 视频演示，但训练计划与饮食弱，中文深度浅。
- **ExRx.net**：专业动作库，面向教练，门槛高。
- **中文内容**：硬派健身、斌卡《健身笔记》等单点内容强，但**没有把「动作库＋计划＋饮食＋视频精选」串成一条路径的中文站**；优质视频散落在平台算法里，新手无法系统找。
- 结论 → 本站定位：**把「练什么、怎么练、吃什么、跟谁学」四件事连起来**的中文一站式指南。

### 1.2 循证共识（内容准确性的基准，写入站内）
- **训练容量**：每肌群每周 10–20 个有效组（新手 6–10 起步即有效）；Pelland 2025/26《The Resistance Training Dose Response》meta 回归（Sports Medicine）证实剂量-反应关系。来源：pubmed.ncbi.nlm.nih.gov/41343037
- **强度**：复合动作每组留 1–3 RIR（离力竭 1–3 次）；组间休息：复合 2–3 分钟、孤立 60–90 秒。
- **频率**：同一肌群每周 ≥2 次（把容量拆开比一次练爆好）。
- **渐进超负荷**：加重量或加次数（双重渐进）是长期进步第一变量。
- **蛋白质**：1.6–2.2 g/kg/天（Morton 2018, BJSM：低于 1.6 补蛋白有效、超过后增益趋缓；减脂期靠上沿保肌）。来源：bjsm.bmj.com/content/52/6/376；PMC8978023
- **减脂**：热量缺口 15–20%，每周减 0.5–1% 体重，蛋白拉高＋力量训练保肌。
- **补剂**：肌酸一水 3–5g/天证据最强；蛋白粉是「方便」非「必须」；咖啡因训练前 3–6mg/kg。
- → 这些数字写进动作组次、计划渐进规则、饮食计算器和补剂「证据等级」。

### 1.3 创作者生态（四平台差异）
- **B站**：中长视频系统教学/科普。已核实：帕梅拉 1502 万、周六野Zoey 1074 万、韩小四 523 万、帅soserious 429 万、叔贵 287 万、Bruce_PhD 124 万、健助师_小珂 50.8 万、ALEX 26.5 万、一介粗人 23.8 万、桑禹涵Sky 19.1 万（共 10 位）。
- **抖音**：短平快＋直播跟练（刘畊宏约 5900 万、欧阳春晓 923 万、陈康 73.5 万、鹿晨辉、孙良轩）。
- **小红书**：女性向塑形/体态/减脂笔记（帕梅拉、周六野、叔贵、韩小四、欧阳春晓等同名账号）。
- **YouTube**：英文科学密度最高（Jeff Nippard、RP、ATHLEAN-X、Alan Thrall、MegSquats、Jeremy Ethier）。
- **验证方式**：B站创作者经官方 API 实时核实（粉丝数为构建当日返回值）；YouTube 经 oembed 核实标题与频道；抖音/小红书链接 HTTP 实测可达。所有链接在站内 README 说明复核方法。

## 二、网站方案

### 2.1 定位与命名
- 名称：**铁引力 IRON GRAVITY** —— 「对抗重力，就是训练本身」。
- 定位：中文、循证、干净、可执行；目标用户：新手～进阶训练者。

### 2.2 信息架构（5 页）
1. **首页**：定位 + 四大模块入口 + 「今日推荐」（随机动作/计划）+ 实时数据统计。
2. **动作库**：50 个精选动作，按肌群/器械/难度/关键词筛选；动作卡 = 要点 / 常见错误 / 组次建议 / 替代动作（与计划互链）。
3. **训练计划**：5 套计划（新手全身 / 上下肢四分化 / 推拉腿·PPL / 经典力量 5×5 / 减脂塑形），含每周课表、渐进规则、动作跳转；顶部「30 秒选计划」决策器。
4. **饮食营养**：TDEE 计算器（Mifflin-St Jeor）→ 目标热量与三大宏量 → 30 种常见食物速查 → 增肌/减脂一日示例餐单 → 补剂证据等级表。
5. **视频精选**：26 位创作者 + 40 条精选视频，双层分类（平台 × 主题）；B站视频站内嵌入播放，其他平台一键跳转；每位创作者附「一句话看点」与「适合谁」。

### 2.3 技术选型
- 纯静态 HTML+CSS+原生 JS，**零框架零 CDN**（离线/断网可开）。
- 数据与视图分离：`assets/js/data-*.js`（内容）＋ `app.js`（交互）＋ `style.css`；改内容不用碰代码。
- `file://` 双击即用（全部 `<script>` 加载，不用 fetch）；附 `serve.cmd` 一键本地服务。
- 响应式（手机/平板/桌面）；深色主题；系统字体栈（不依赖外部字体）。

### 2.4 视觉
- 深色「铁馆」风：`#0A0B10` 底 ＋ 荧光青绿主色 ＋ 橙色点缀；大数字、卡片布局、克制动效。

## 四、构建与验证记录（2026-10-15 完成）

- 站点「铁引力」5 页：首页 / 动作库 / 训练计划 / 饮食营养 / 视频精选（纯静态，双击 `index.html` 即用）。

### 验证结果（全部为实际执行输出）
- 语法：15 个 JS 文件 `node --check` 全部通过。
- 数据自检：50/5/26/35/30/5，id 互链完整 → 校验通过 ✓。
- 外链复检：**64 条实测在案，64 OK / 0 失败**（B站经官方 API 核验粉丝数与标题；YouTube 经 oembed 核验；文献经 Europe PMC 核对编号）。
- 页面渲染：无头 Chrome 以 `file://`（用户双击的真实场景）逐页导出渲染后 DOM——动作卡 50、创作者卡 26、食物行 30、计划周表 7 行、计算器结果正常输出。
- 本地服务：`tools/selftest.mjs` 逐项请求 8/8 全部 200 ✓。
- 截图自查（无头渲染 → 逐张目检）：发现并修复 4 处——① 计算器大数字舍入差（2630→2633 与 TDEE 对齐）② 全局灰字对比度提亮一档 ③ 休息日信息重复显示 ④ 「器械」筛选项改名「固定器械」+ 补齐决策器默认选中态。
- 已在 1440 / 1280 / 1200 三种宽度下目检全部 5 页，无溢出/错位；截图存于 `docs/screenshots/`。

### 诚实说明
- **未使用用户的浏览器/桌面控制能力**：所有联网核验走直连 API/HTTP，页面自查用独立临时配置的无头 Chrome 渲染本地文件。

## 八、v5 扩展（2026-10-15，第五轮，剩余已批准项全清）

### 图源拍板记录（用户授权 assistant 自决）
**选择：自绘 SVG 线稿（ex-art.js），并放弃 B站封面直链。**
- 理由：整个站点的核心卖点是「零依赖、双击即用、离线可用」——封面直链会引入 ① 外链失效随时间腐化（与 v1「只链不搬」的教训一致）、② 热链接版权与防盗链不确定性、③ 图与动作不完全对版。线稿小人则 100% 离线、版权干净、可随浅色主题换色、还能进打印动作卡。
- 匹配策略：按「动作模式」规则表（14 种模板，如 squat/lunge/hinge/bench/press/pull/core…）对 60 个动作自动归类；未命中兜底站姿模板，永不空白。
- **可回退路径**：渲染处全部包了 `window.IG_ART ? … : ""` 守卫——删掉 ex-art.js 或它加载失败时自动纯文字显示，页面其它功能零影响；将来若换封面直链，只需替换 IG_ART.of() 一个函数。

### 本轮新增
- **动作线稿图示**：动作库 60 张卡 + 详情页大图；颜色走 currentColor / var(--acc)，双主题自适应。
- **练前热身序列**：exercises.html 顶部 8 步通用热身卡（data-warmup.js，时长+要点），避免筛选器被「热身」类污染。
