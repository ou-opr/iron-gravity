# docs/legacy —— 退役的图示样板页

这里放的是 v5–v7 期间用来**比对图示方案**的独立演示页，早已不在站点主链路里，也不被任何脚本或页面引用。

| 文件 | 当年用途 |
|---|---|
| `art-poc.html` | 最早的自绘线稿概念验证（v5 图源拍板阶段） |
| `atlas-demo.html` | 肌群级解剖面板的 12 格复取样张（v9 atlas 引入时） |
| `placard-frames-demo.html` | 动作帧说明牌的双帧布局试验（v8） |
| `placard-samples.html` / `placard-samples2.html` | 23 个模板的逐格目检样张（v10 自评循环用） |

保留它们的原因：这些页面记录了「为什么最终选这套图示」，出问题时能回看；但它们和站点发布无关，部署时排除 `docs/` 即可。

**注意**：这些页面只在本目录下引用 `../../assets/js/*`，路径已按新位置修正；如果再把目录搬走，需要同步改路径。
